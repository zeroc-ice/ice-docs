{% language-section name="lang-1" %}
The Slice built-in types are mapped to Java types as follows:

| **Slice** | **Java** |
| --- | --- |
| bool | `boolean` |
| byte | `byte` |
| short | `short` |
| int | `int` |
| long | `long` |
| float | `float` |
| double | `double` |
| string | `String` |

{% /language-section %}
