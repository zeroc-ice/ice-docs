{% language-section name="lang-1" %}
The Slice built-in types are mapped to JavaScript and TypeScript types as follows:

| **Slice** | **JavaScript** | **TypeScript** |
| --- | --- | --- |
| bool | `Boolean` | `boolean` |
| byte | `Number` | `number` |
| short | `Number` | `number` |
| int | `Number` | `number` |
| long | `BigInt` | `bigint` |
| float | `Number` | `number` |
| double | `Number` | `number` |
| string | `String` | `string` |

{% /language-section %}
