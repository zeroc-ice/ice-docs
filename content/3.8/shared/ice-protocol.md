title: Ice Protocol
---

The Ice protocol is an [application-layer protocol](https://en.wikipedia.org/wiki/Internet_protocol_suite#Application_layer) that defines a number of message types exchanged between clients and servers, together with rules as to what message is to be sent under what circumstances.

Some of these messages carry a data payload encoded using the [Ice encoding](../ice-encoding).

There is only one version of the Ice protocol, version 1.0.
