{% language-section name="lang-1" %}

The [Dispatcher](../../../basics/terminology) abstraction corresponds to the Swift
[Dispatcher protocol](https://code.zeroc.com/ice/3.8/api/swift/documentation/ice/dispatcher)

```swift
public protocol Dispatcher: Sendable {
    func dispatch(_ request: sending IncomingRequest) async throws ->
      OutgoingResponse
}
```

A dispatcher is any type that implements this protocol.

{% /language-section %}

{% language-section name="lang-2" %}

In Swift, a servant is a “terminal dispatcher”: a type that implements the Dispatcher abstraction by itself, without
delegating to another object.

The most common Swift servants adopt a [skeleton protocol](../../../slice/interfaces#skeleton-protocols) generated by
the Slice compiler, along with an extension that implements `dispatch` by:

- unmarshaling input parameters
- calling the protocol method for the operation named by the request (you implement this method in your servant)
- creating a response from the return value and out parameters returned by this method

This `dispatch` also implements the 4 operations defined on `Object`: it calls your servant's own implementation when
your servant adopts `Ice.Object`, and a default implementation otherwise.

{% /language-section %}
