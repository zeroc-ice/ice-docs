## Ice for Ruby

The [zeroc-ice](https://rubygems.org/gems/zeroc-ice) gem provides Ice for Ruby 3.4 and later on Linux and macOS, with
the Slice-to-Ruby compiler (`slice2rb`):

```shell
gem install zeroc-ice
```

`gem` builds the Ice extension from source, which requires a C++ compiler and the bzip2 development headers, plus the
OpenSSL development headers on Linux.
