## Ice for MATLAB

Ice for MATLAB is a MATLAB toolbox for MATLAB R2025b. The toolbox holds the Ice for MATLAB library and the
Slice-to-MATLAB compiler (`slice2matlab`). Download the toolbox for your platform:

- Linux: [ice-3.8.3.0-R2025b-linux.mltbx](https://download.zeroc.com/ice/3.8/ice-3.8.3.0-R2025b-linux.mltbx)
- Windows: [ice-3.8.3.0-R2025b-win.mltbx](https://download.zeroc.com/ice/3.8/ice-3.8.3.0-R2025b-win.mltbx)

Then install it from MATLAB:

```matlab
matlab.addons.install('ice-3.8.3.0-R2025b-linux.mltbx')
```

Development of Ice for MATLAB was sponsored by [ETAS GmbH](https://www.etas.com).
