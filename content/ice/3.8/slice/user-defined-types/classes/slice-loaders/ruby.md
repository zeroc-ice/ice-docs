{% language-section name="custom-slice-loaders" %}

A custom Slice loader is an object with a `newInstance` method that takes a type ID and returns a new instance, or
`nil`. You install it by setting the `sliceLoader` attribute of [InitializationData](api:Ice/InitializationData):

```ruby
class NodeLoader
    def newInstance(typeId)
        typeId == "::Demo::Node" ? MyNode.new : nil
    end
end

initData = Ice::InitializationData.new
initData.sliceLoader = NodeLoader.new
Ice.initialize(initData) do |communicator|
    ...
end
```

Ice for Ruby calls your Slice loader only for Slice classes: for a Slice exception, it always creates an instance of the
class generated by `slice2rb`.
