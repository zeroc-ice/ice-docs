{% language-section name="mapping" %}

The Slice built-in types are mapped to MATLAB types as shown in this table:

| **Slice** | **MATLAB**                                                                                |
| --------- | ----------------------------------------------------------------------------------------- |
| `bool`    | `logical`                                                                                 |
| `byte`    | `uint8`                                                                                   |
| `short`   | `int16`                                                                                   |
| `int`     | `int32`                                                                                   |
| `long`    | `int64`                                                                                   |
| `float`   | `single`                                                                                  |
| `double`  | `double`                                                                                  |
| `string`  | character vector (1-by-n array of `char`), empty 1-by-0 character array for empty strings |

{% /language-section %}
