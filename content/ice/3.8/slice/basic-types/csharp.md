{% language-section name="mapping" %}

The Slice built-in types are mapped to C# types as shown below:

| **Slice** | **C#**   |
| --------- | -------- |
| `bool`    | `bool`   |
| `byte`    | `byte`   |
| `short`   | `short`  |
| `int`     | `int`    |
| `long`    | `long`   |
| `float`   | `float`  |
| `double`  | `double` |
| `string`  | `string` |

{% /language-section %}
