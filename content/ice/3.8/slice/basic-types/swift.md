{% language-section name="mapping" %}

The Slice built-in types are mapped to Swift types as shown below:

| **Slice** | **Swift** |
| --------- | --------- |
| `bool`    | `Bool`    |
| `byte`    | `UInt8`   |
| `short`   | `Int16`   |
| `int`     | `Int32`   |
| `long`    | `Int64`   |
| `float`   | `Float`   |
| `double`  | `Double`  |
| `string`  | `String`  |

{% /language-section %}
