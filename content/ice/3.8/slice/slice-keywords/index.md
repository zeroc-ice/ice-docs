title: Slice Keywords
sidebarLabel: Keywords
---

The following identifiers are Slice keywords. Keywords are case-sensitive. To use a keyword as an identifier, escape it
with a backslash; see [Escaped Identifiers](../lexical-rules#escaped-identifiers).

- [`bool`](../basic-types#booleans)
- [`byte`](../basic-types#bytes)
- [`class`](../user-defined-types/classes)
- [`const`](../constants-and-literals)
- [`dictionary`](../user-defined-types/dictionaries)
- [`double`](../basic-types#floating-point-types)
- [`enum`](../user-defined-types/enumerations)
- [`exception`](../exceptions)
- `extends`: [interface](../interfaces/interface-inheritance), [class](../user-defined-types/classes/class-inheritance),
  and [exception](../exceptions#exception-inheritance) inheritance
- [`false`](../basic-types#booleans)
- [`float`](../basic-types#floating-point-types)
- [`idempotent`](../operations#idempotent-operations)
- [`int`](../basic-types#integer-types)
- [`interface`](../interfaces)
- [`long`](../basic-types#integer-types)
- [`module`](../modules)
- [`Object`](../interfaces/interface-inheritance#implicit-inheritance-from-object), the base of all interfaces
- `optional`: [parameters and return values](../operations#optional-parameters-and-return-values) and
  [fields](../fields#optional-fields)
- [`out`](../operations#operation-syntax)
- [`sequence`](../user-defined-types/sequences)
- [`short`](../basic-types#integer-types)
- [`string`](../basic-types#strings)
- [`struct`](../user-defined-types/structures)
- [`throws`](../exceptions#exception-specification-in-operations)
- [`true`](../basic-types#booleans)
- [`Value`](../user-defined-types/classes/class-inheritance#implicit-inheritance-from-value), the base of all classes
- [`void`](../operations#operation-syntax)
