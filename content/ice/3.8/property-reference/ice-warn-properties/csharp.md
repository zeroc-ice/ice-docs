## Ice.Warn.AMICallback

{% synopsis %}

`Ice.Warn.AMICallback=num`

{% /synopsis %}

{% description %}

If `num` is set to a value larger than 0, the Ice runtime logs a warning when an AMI callback throws an exception. The
default value is 1.

{% /description %}
