---
title: Navigation Within an Application Tab
---

Each Application tab maintains a history of the nodes you have visited in this tab. You can navigate these nodes using
the `View > Go Back to the Previous Node` and `View > Go to the Next Node` menu items, or with the equivalent toolbar
buttons:

![navigation-arrows.png](/images/ice/3.8/navigation-within-an-application-tab/navigation-arrows.png)

Also on some forms a green arrow button provides a link to another node (typically a template) in the same Application
pane:

![template-arrow.png](/images/ice/3.8/navigation-within-an-application-tab/template-arrow.png)
